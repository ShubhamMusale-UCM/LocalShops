# UI Upgrade Skill

This skill is invoked when you need to redesign or upgrade the user interface of a specific screen or component in the CityLocalShop app.

## Resources
- **UI Files Summary**: You have access to a comprehensive list of all UI files and what they do in `UI_FILES_SUMMARY.md` in this directory. Reference this file when you need to know which file to modify for a specific UI task.
- **Design Guidelines**: Refer to `ui files summary.md` (at the root of the project) for the master design prompt and aesthetic guidelines.

## Workflow
1. When asked to upgrade a UI, identify the relevant files using `UI_FILES_SUMMARY.md`.
2. Review the target file to understand its current implementation and props.
3. Apply modern, premium design concepts (e.g., Glassmorphism, animations, smooth transitions, premium typography) as per the design guidelines.
4. Update or replace components.
5. Provide a summary of the changes to the user.
